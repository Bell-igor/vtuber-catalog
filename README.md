# Сайт-каталог для VTuber — Belligor

**Сайт опубликован:** https://bell-igor.github.io/vtuber-catalog/
**Репозиторий:** https://github.com/Bell-igor/vtuber-catalog

Обновление контента: открыть в репозитории `assets/js/config.js` → карандаш (Edit) → правки →
**Commit changes**. Через минуту-две изменения появятся на сайте. Новые картинки добавляются
кнопкой **Add file → Upload files** в папку `assets/img/gallery/`.

Одностраничный сайт: сверху её заставка (кадр + короткая видео-петля) и ссылки — Twitch,
Telegram, Discord, Фетта и донат, ниже видео с эфиров (клипы подтягиваются автоматически),
модель и арт, ещё ниже — анонсы из Telegram и кредитсы с именами авторов.

Главное: сайт **не использует внешние сервисы** — ни шрифтов Google, ни библиотек с CDN,
ни картинок со сторонних хостингов. Поэтому он одинаково открывается и из СНГ, и за рубежом,
без VPN, и грузится быстро даже на слабом интернете.

---

## 1. Посмотреть сайт сейчас

Откройте файл `index.html` двойным щелчком — сайт работает прямо с диска, без интернета.
Пока стоит демо-наполнение: сверху висит жёлтая плашка «Это демонстрационное наполнение».

## 2. Что где лежит

```
site/
  index.html              ← главная страница (править почти не нужно)
  404.html                ← страница «не найдено» для GitHub Pages
  robots.txt              ← разрешение поисковикам
  status.json             ← живой статус: эфир, анонсы, статистика (обновляется сам)
  .nojekyll               ← нужен для GitHub Pages
  .github/
    workflows/status.yml         ← автообновление статуса (каждые 5 минут)
    scripts/update-status.mjs    ← сбор данных: Twitch, Telegram, Discord
  assets/
    css/style.css         ← оформление, цвета — в блоке :root в начале файла
    js/config.js          ← ВСЁ СОДЕРЖИМОЕ САЙТА: имя, ссылки, галерея, кредитсы
    js/app.js             ← логика (галерея, увеличение, перевод) — править не нужно
    img/
      banner-zastavka.webp ← кадр из её заставки — баннер на первом экране
      art-chibi.webp      ← анимированный чиби-арт (в галерее)
      art-chibi-thumb.webp ← превью чиби для сетки
      avatar-twitch.png   ← аватар, подтягивается с Twitch автоматически
      avatar-twitch.webp  ← то же в webp (сжимается автоматически для скорости)
      model-blink.webp    ← анимация модели на первом экране (моргает)
      model-blink-poster.webp ← первый кадр анимации — показывается, пока она грузится
      model-sheet.webp    ← лист модели — в карусели кредитсов
      model-full.webp     ← модель целиком — открывается при клике в галерее
      model-card.webp     ← карточка модели для галереи
      model-body.webp     ← модель: слои для простого варианта анимации
      model-head.webp     ← модель: голова (поворачивается)
      model-hand.webp     ← модель: рука (качается)
      og.jpg              ← превью для соцсетей (Telegram, Discord, X)
      favicon.svg         ← иконка вкладки
      gallery/            ← сюда складывать остальной арт (пока пусто)
```

## 3. Заполнить своими данными

Откройте `assets/js/config.js` любым текстовым редактором (подойдёт «Блокнот», лучше — VS Code
или прямо редактирование на GitHub в браузере). Это единственный файл, который нужно менять.

| Что | Где в файле |
|---|---|
| Имя, подпись, слоган, пара слов о себе | `owner` |
| Аватар и баннер (подтягиваются с Twitch сами) | `owner.avatar`, `owner.banner` |
| Кнопки-ссылки (Twitch, Telegram, Discord, Фетта, донат) | `links` |
| Модели для карусели в кредитсах | `models` |
| Баннер первого экрана | `owner.banner`, `owner.bannerVideo`, `owner.bannerSound` |
| Арт по модели | `gallery` (пока пусто — см. раздел 4) |
| Клипы и записи эфиров | `clips` (подтягиваются с Twitch сами) |
| Кредитсы по разделам | `credits.sections` |
| Список «отдельное спасибо» | `credits.thanks` |
| Текст подвала и ссылка на зеркало | `footer` |
| Плашка «демо» | `demo: true` → поставьте `false`, когда всё заполните |

Текст пишется в двух языках: `{ ru: "…", en: "…" }`. Если английская версия не нужна —
продублируйте русский текст.

Пример новой ссылки:

```js
links: [
  { label: "YouTube", url: "https://youtube.com/@ваш_канал", accent: "yt" },
  { label: "Boosty",  url: "https://boosty.to/ваш_ник",     accent: "boosty" }
]
```

`accent` задаёт цвет точки у кнопки: `yt`, `twitch`, `tg`, `x`, `discord`, `vk`, `boosty`,
`tiktok`, `inst`, `site`. Ссылки-заглушки начинаются с `#` — сайт сам помечает их как «демо».

Пример новой карточки в галерее:

```js
{
  kind: "art",                                     // model | art | video | photo
  title: { ru: "Арт от Кая", en: "Art by Kai" },
  alt:   { ru: "Описание картинки для незрячих и для поиска", en: "…" },
  thumb: "assets/img/gallery/art-kai-thumb.webp",  // что показывать в сетке
  src:   "assets/img/gallery/art-kai.webp",        // что открывать при клике
  w: 896, h: 1195,                                 // реальные размеры картинки (чтобы не «прыгала» сетка)
  artist: { name: "Кай", url: "https://x.com/ник" }
}
```

Карточка-видео вместо картинки: вместо `src` укажите `video: "https://youtube.com/watch?v=…"` —
тогда плитка ведёт на видео.

Пример кредитса:

```js
{
  role: { ru: "Риггинг", en: "Rigging" },
  name: "Ник",
  handle: "@nick",
  url: "https://x.com/nick"
}
```

## 3а. Баннер первого экрана

На первом экране — статичный кадр из её заставки (`banner-zastavka.webp`). Видео поверх
баннера отключено: в `config.js` строка `bannerVideo` закомментирована. Если захочется
вернуть анимацию, положите файл `banner-loop.mp4` в `assets/img/` и раскомментируйте строку —
видео само зациклено и загружается после отрисовки страницы.

Если у видео появится звук: поставьте `bannerSound: true` — в углу баннера появится
кнопка «включить/выключить звук».

Поменять картинку баннера: заменить `banner-zastavka.webp` в `assets/img/` (удобнее всего
сделать кадр из заставки — 1600×900).

## 4. Кредитсы и модели

В кредитсах — **карусель** «Модель и арты» (`credits.carousel`): стрелки по бокам листают
слайды, у каждого слайда своя картинка, подпись и авторы (роль → имя → ник → ссылка).
Сейчас в ней 11 слайдов: две модели (модель в полный рост и хэллоуин-модель — лист модели,
арт Weritasse, риг Orin) и 9 артов. Добавить новый — допишите объект в массив
`carousel` (картинка, название, авторы). Листается стрелками, свайпом на телефоне и
стрелками клавиатуры, когда блок в фокусе.

Ниже — обычные разделы (`credits.sections`): оформление, звук и видео.

Ссылки с пометкой `pinned: true` (сейчас это Фетта и донат) дублируются в шапке сайта
и в подвале — кнопками со значками.

## 4а. Добавить арт по модели

1. Положите файлы в `assets/img/gallery/` (png, jpg или webp — любой формат).
2. Впишите их в `gallery` в `config.js` (образец есть в комментарии внутри файла).

Если картинок много и они тяжёлые, уменьшите их до ~1100 px по длинной стороне и сделайте
WebP — так страница будет открываться быстрее. Для этого в папке проекта (рядом с `site`)
лежит готовый скрипт `tools/build-images.py`. Сам скрипт на хостинг загружать не нужно.

Картинки обязательно держите **на том же сайте** (в этой папке), а не ссылкой на Discord,
Imgur или Pinterest: у российских провайдеров чужие CDN часто недоступны, и у зрителей
вместо арта будет пустое место.

Аватар и баннер загружать не нужно — они подтягиваются с её Twitch автоматически
и сжимаются в webp прямо в GitHub (шаг «Сжать картинки с Twitch в webp»).

## 4б. Модель и её анимация

На первом экране модель **моргает** — это готовая анимация из присланного видео
(`assets/img/model-blink.webp`, 49 кадров, 3,9 секунды). Что делает сборка:

- белый фон вырезается заливкой от краёв (контур и заливки персонажа целы);
- кадры прореживаются (каждый второй) — для моргания этого достаточно, а файл вдвое легче;
- видео зациклено само, поэтому петля без стыка.

Пока анимация загружается, показывается её первый кадр (`model-blink-poster.webp`, 23 КБ),
поэтому шапка появляется мгновенно, а сама анимация (≈650 КБ) догружается после отрисовки
страницы. Если у зрителя включено «уменьшить движение», вместо анимации остаётся статичный кадр.

Пересобрать из нового видео: положите файл в папку проекта и запустите `tools/build-blink.py`
(он вырежет фон, проредит кадры и соберёт webp).

Есть и запасной вариант — простая сборка из трёх слоёв (`model-body/head/hand.webp`)
с покачиванием головы. Он включается, если в `config.js` убрать строку `animation`;
углы и точки вращения настраиваются там же (`headAngle`, `handAngle`, `headPivot`, `handPivot`).

## 5. Живой статус и анонсы (работает само)

На сайте есть:

- красный мигающий значок **«Сейчас в эфире»** в шапке и карточка эфира: название стрима,
  игра, сколько уже идёт, число зрителей и кнопка «Смотреть стрим»;
- раздел **«Анонсы и события»** — последние посты из Telegram-канала;
- цифры: фолловеры на Twitch, подписчики в Telegram, участники Discord;
- **аватар** автоматически подтягивается с Twitch (и обновляется, если она его сменит).

Всё это лежит в файле `status.json`, который обновляет GitHub Actions каждые 5 минут
(`.github/workflows/status.yml` + `.github/scripts/update-status.mjs`). Если ничего не изменилось,
коммита не будет — история репозитория не засоряется.

- **Запустить вручную:** GitHub → вкладка **Actions** → «Обновление статуса стрима» → **Run workflow**.
- **Как быстро появляется значок:** обычно 1–2 минуты после старта стрима, в худшем случае
  около 5 минут (GitHub иногда задерживает расписание). Пока вкладка открыта, сайт дополнительно
  сам проверяет эфир каждую минуту через открытый API — это ускоряет появление значка.
- **Если сайт не смог получить данные**, он показывает обычное «Не в эфире» — ничего не ломается.
- **Точность:** без ключей данные берутся из открытых источников (ivr.fi, gql.twitch.tv).
  Хотите 100% официальные данные — создайте приложение на [dev.twitch.tv](https://dev.twitch.tv/console/apps)
  и добавьте в репозиторий секреты `TWITCH_CLIENT_ID` и `TWITCH_CLIENT_SECRET`
  (Settings → Secrets and variables → Actions). Скрипт сам начнёт их использовать.
- **Другие ники/каналы:** блок `live` в `config.js`, а для автосбора — переменные окружения
  в `status.yml` (`TWITCH_LOGIN`, `TG_CHANNEL`, `DISCORD_INVITE`).

## 6. Как выложить в интернет (бесплатно)

### Вариант A. GitHub Pages — рекомендуется

Бесплатно, без рекламы, HTTPS, можно подключить свой домен, файлы легко обновлять.

1. Зарегистрируйтесь на [github.com](https://github.com).
2. Кнопка **New repository** → имя, например `catalog` → выберите **Public** → **Create**.
3. На странице репозитория: **Add file → Upload files** → перетащите **содержимое** папки
   `site` (именно файлы `index.html`, `404.html`, `.nojekyll` и папку `assets`, а не саму папку
   `site`) → **Commit changes**.
4. **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → **Save**.
5. Через 1–2 минуты адрес будет таким: `https://ваш-логин.github.io/catalog/`.

Обновление потом: открыть `assets/js/config.js` в репозитории → карандаш → править →
**Commit changes**. Либо снова **Add file → Upload files** для новых картинок.

### Вариант B. Neocities — проще всего, перетаскиванием

1. Регистрация на [neocities.org](https://neocities.org) (бесплатный тариф — 1 ГБ, рекламы нет).
2. **Dashboard → Drag & drop** — перетащите `index.html` и папку `assets`.
3. Адрес: `https://ваш-логин.neocities.org`. Хорошо открывается из СНГ.

### Вариант C. Свой домен + два зеркала — максимальная надёжность

1. Купите домен (`.ru` или `.com`, 200–900 ₽/год у reg.ru, timeweb и подобных).
2. У регистратора добавьте DNS-запись: `CNAME` → `ваш-логин.github.io`.
3. В GitHub: **Settings → Pages → Custom domain** → впишите домен → **Enforce HTTPS**.
4. Сделайте копию сайта на втором хостинге (Neocities или российский статик-хостинг) и
   впишите адрес в `footer.mirror` в `config.js` — в подвале появится ссылка «Зеркало сайта».

### Чего лучше избегать

- **Cloudflare Pages (`*.pages.dev`)** — домен блокируется в России
  ([сообщения пользователей и разработчиков](https://community.cloudflare.com/t/whole-pages-dev-blocked-in-my-country/654598/2)).
- **Vercel / Netlify** — у части российских провайдеров перестали открываться
  ([разбор с переездом на российский хостинг](https://habr.com/ru/articles/1011050/)).
- **Carrd** — как конструктор работает, но на бесплатном тарифе нет нормальной галереи
  с увеличением картинок и ограничено число блоков; к тому же часть оформления тянется
  с их CDN. Наш вариант — те же деньги (0 ₽), но без этих ограничений.

## 7. Проверить, что открывается из СНГ и из-за рубежа

- [check-host.net](https://check-host.net/check-http) — введите адрес сайта: покажет ответ из
  России, Казахстана, Европы, США.
- [isitblockedinrussia.com](https://isitblockedinrussia.com) — быстрая проверка домена.
- Попросите пару зрителей из разных городов открыть сайт с телефона (мобильный интернет
  и домашний Wi-Fi — это разные провайдеры).

## 8. Мелочи, которые стоит поправить после публикации

- В `index.html` замените `https://example.github.io/` на свой адрес (строка `canonical`) —
  это подсказка поисковикам.
- Там же в `og:image` / `og:title` указан адрес картинки-превью: для корректного превью
  в Telegram и Discord лучше указать полный адрес `https://ваш-домен/assets/img/og.jpg`.
- Плашку «демо» убирает `demo: false` в `config.js`.
- Цвета меняются в `assets/css/style.css`, блок `:root` в самом начале (`--gold`, `--bg` и т. д.).
- Хотите только русскую версию — уберите английские тексты в `config.js` и кнопку `RU/EN`
  в `index.html` (`<button id="langBtn" …>`).

## 9. Про авторские права и 18+

- Публикуйте арт только с разрешения авторов и всегда указывайте имя и ссылку —
  сайт для этого и сделан. В подвале уже есть строка: «если вы автор и хотите что-то
  изменить или убрать — напишите мне».
- Если в галерее будет взрослый контент, для него лучше сделать отдельную страницу
  с предупреждением и подтверждением возраста, а не мешать с основным каталогом.
